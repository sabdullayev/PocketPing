## Статус разработки (Roadmap)

- [x] **[2026-10-28] — Оптимизация экрана Body, полноэкранный редактор, адаптивный тулбар и кнопка закрытия ответа:**
  - **100% высоты для вкладок запроса при отсутствии ответа:** Убран громоздкий плейсхолдер "Ready to ping", съедавший более 57% экрана. До получения ответа (`state.response == null`) вкладка Body (и другие вкладки) занимает всю полезную высоту экрана (> 500dp).
  - **Адаптивный скролл и скрытие при клавиатуре:** При открытии клавиатуры блок ответа гарантированно скрывается, давая редактору максимальное пространство без урезания строк.
  - **Реорганизация тулбара Body:** 
    - Верхний ряд: аккуратные чипсы выбора типа (`None`, `JSON`, `Raw Text`).
    - Второй ряд: слева быстрые сниппеты (`{}`, `[]`, `"key": "val"`), справа удобные экшн-кнопки `[ 🪄 Beautify ]`, `[ ⛶ Expand ]` (полноэкранный режим) и `[ ⌨️ Done ]` (скрытие клавиатуры).
  - **Кнопка закрытия ответа `[X]`:** В `MetricsBarWidget` добавлена яркая кнопка `[X]` (Close), при тапе на которую вызывается `ClearResponseEvent()`, стейт ответа сбрасывается в `null`, и редактор мгновенно возвращается к 100% высоте. Панель метрик обернута в горизонтальный скролл без возможности переполнения даже на узких 300px экранах.
  - **Тестовое покрытие:** Разработаны `test/body_tab_view_overflow_test.dart` и `test/metrics_bar_widget_test.dart` (22 теста проходят успешно).

## Журнал изменений (Changelog)

### [2026-10-28] — Фикс 401 ошибки (Bearer), интерактивный диалог cURL, компактный URL-бар и фикс Response окна
- **Статус:** Выполнено, протестировано (`flutter analyze` — 0 issues, `flutter test` — 9 passed, установлено на Xiaomi).
- **Новые возможности и исправления:**
  - **Устранение ошибки 401 Unauthorized (Bearer):** Пользователи часто вставляют токен вместе со словом `Bearer `. Ранее PocketPing автоматически добавлял префикс, в результате чего отправлялся заголовок `Authorization: Bearer Bearer <token>`, приводящий к отказу сервера с кодом 401. Добавлена очистка префикса на трех уровнях (`http_request_entity.dart`, `auth_tab_view.dart` при вставке и при ручном вводе). Проверено с реальным API `https://api.biznex.uz/` — статус 200 OK.
  - **Компактная строка URL (исправление пустого пространства):** Заменены громоздкие `IconButton` (48x48) на компактные `InkWell` с `suffixIconConstraints: BoxConstraints(minWidth: 0, minHeight: 0)`. Кнопка `{}` и крестик очистки теперь имеют плотные отступы, устраняя лишнее пустое пространство в строке адреса.
  - **Диалог cURL Import & Export:** Кнопка `cURL` в AppBar теперь открывает удобный модальный диалог с многострочным полем ввода, кнопками «Paste from Clipboard», «Import to Request» и «Copy Current Request as cURL» (`CurlParser.toCurl`). Парсер обновлен для поддержки Swagger/OpenAPI и Chrome DevTools cURL форматов, нормализации умных кавычек и bash-переносов строк.
  - **Отображение блока ответа при большом количестве параметров:** Секция ответа теперь всегда отображается при наличии `response != null` (не скрывается при открытой клавиатуре или анимации скрытия), а при нажатии «Send» гарантированно вызывается глобальный `unfocus()`.

### [2026-10-28] — Кнопка закрытия ответа [X], фильтрация истории по HTTP-методам и фикс верстки
- **Статус:** Выполнено, протестировано на эмуляторе (`flutter analyze` — 0 issues, `flutter test` — 7 passed).
- **Новые возможности и исправления:**
  - **Кнопка закрытия `[X]` для блока ответа:** В `MetricsBarWidget` справа от плашки размера ответа добавлена кнопка `[X]`. При нажатии отправляется `ClearResponseEvent` в `RequestBuilderBloc`, который сбрасывает `response` в `null` и возвращает экран к чистому состоянию *"Ready to ping"*.
  - **Фильтрация истории запросов по HTTP-методам:** В `HistoryScreen` добавлен горизонтальный скроллируемый ряд чипов `ChoiceChip` (`ALL`, `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD`), окрашенных в соответствующие цвета методов. Фильтрация работает реактивно совместно с поисковой строкой по URL.
  - **Устранение оверфлоу в диалоге переменных:** В `EnvironmentsManagerDialog` устранен баг `OVERFLOWED BY 1.0 PIXELS` в строке `Variables ({{variable_name}}) + Add Variable`. Текст обернут в `Expanded` с `TextOverflow.ellipsis`, а кнопка сжата компактными паддингами.

### [2026-10-28] — Поддержка {var}, VS Code Autocomplete (IntelliSense) и 120 FPS виртуализация скролла
- **Статус:** Выполнено, протестировано на эмуляторе (`flutter analyze` — 0 issues, `flutter test` — 7 passed).
- **Новые возможности:**
  - **Поддержка одиночных скобок `{var}` и двойных `{{var}}`:** В `SubstituteEnvVariablesUseCase` добавлен регулярный паттерн `r'\{\{?\s*' + key + r'\s*\}\}?'`, поддерживающий как `{base_url}`, так и `{{base_url}}`, с любыми пробелами внутри.
  - **VS Code IntelliSense автокомплит переменных:** При вводе `{` или `{{` в поле URL (или при нажатии быстрой кнопки `{}` в строке адреса) открывается всплывающее окно автокомплита со списком активных переменных. При вводе первой буквы (например `b`) список фильтруется на лету (`{base_url}`). Тап по подсказке мгновенно вставляет переменную и переводит курсор в конец.
  - **Сверхплавный виртуализированный скролл (60/120 FPS):** Разработан `VirtualizedCodeViewer` с фиксированной высотой строки `itemExtent: 22.0`, нумерацией строк (1, 2, 3...) и горизонтальной прокруткой. Прокрутка даже 70-100+ KB ответов (HTML, JSON, текст) работает без малейших фризов и задержек.

### [2026-10-28] — Исправление UI/UX, клавиатуры и синхронизации истории
- **Статус:** Выполнено, протестировано на эмуляторе и реальном телефоне (`flutter analyze` — 0 issues, `flutter test` — 7 passed).
- **Исправленные баги и улучшения:**
  - **Клавиатура и оверфлоу в полях ввода:** Устранен баг `BOTTOM OVERFLOWED BY 48 PIXELS` в `AuthTabView`, обернуты диалоги `SaveToCollectionDialog`, `EnvironmentsManagerDialog`, `CollectionsScreen`, `MonitorScreen` в `scrollable: true` и `Padding` с учётом клавиатуры `View.of(context).viewInsets.bottom`. Секция ответа автоматически скрывается при вводе с клавиатуры, давая всё пространство полям ввода.
  - **Синхронизация истории запросов:** `HistoryBloc` зарегистрирован как синглтон и внедрен в `RequestBuilderBloc`. При успешном выполнении запроса `AddHistoryItemEvent` моментально обновляет стейт в памяти, а при переключении вкладок в `MainNavigationShell` вызывается `LoadHistoryEvent()`. В `HistoryLocalDataSourceImpl` перешли на идемпотентное сохранение по ID `box.put(item.id, item.toMap())`.
  - **Устранение фантомной ошибки cURL:** Добавлен `ClearMessagesEvent()` в `RequestBuilderBloc`, очищающий `errorMessage` и `infoMessage` сразу после отображения SnackBar. Событие смены типа тела запроса (`ChangeBodyTypeEvent`) теперь корректно сбрасывает старые ошибки.
