## Детализация реализованных компонентов

### 1. Request Builder (`features/request_builder`)
* `HttpMethod`: перечисление методов с индивидуальными фирменными цветами.
* `KeyValueParam`: сущность пары ключ-значение с возможностью отключения через чекбокс без удаления.
* `HttpRequestEntity`: агрегирует метод, URL, query-параметры, заголовки, Bearer token и тело.
* `RequestBuilderBloc`: обрабатывает смену URL, методов, динамическое разделение параметров из строки запроса (`?key=val`), форматирование JSON и импорт cURL.

### 2. cURL Parser (`core/utils/curl_parser.dart`)
* Распознает команду `curl ...`.
* Очищает переносы строк bash (`\`).
* Извлекает HTTP метод (`-X`), заголовки (`-H`), Bearer-токен, тело (`-d` / `--data`), адрес и параметры запроса.

### 3. Response Viewer (`features/response_viewer`)
* `HttpResponseEntity`: содержит статус-код, сообщение, миллисекунды, размер, заголовки и тело.
* `MetricsBarWidget`: цветной статус ответа, тайминг и размер.
* `ResponseBodyView`: табы `JSON` (подсветка синтаксиса), `Raw` и `Headers` с кнопкой копирования в буфер обмена.
